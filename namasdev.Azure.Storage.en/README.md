# namasdev.Azure.Storage.en

A simplified Azure Blob Storage repository (`FilesRepository`) wrapping the `Azure.Storage.Blobs` SDK — upload, download, delete, copy/move, and list blobs addressed by `(container, fileName, ...directories)`.

## Install

```
dotnet add package namasdev.Azure.Storage.en --prerelease
```

## Target frameworks

`net48`, `net9.0`
